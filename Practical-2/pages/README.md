# Practical 2: Semantic HTML5 Pages with Accessibility-Ready Structure

## Problem Definition

Develop static HTML5 skeletons for at least 10 StudentHub pages such as Home, About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, and Feedback.

The pages use semantic HTML5 tags and an accessibility-friendly structure to create a clear, well-organized StudentHub website.

---

## Objectives

- Create at least 10 StudentHub web pages using HTML5.
- Use semantic HTML5 elements instead of unnecessary `<div>` elements.
- Create a consistent structure across all pages.
- Make the pages accessibility-friendly.
- Provide meaningful headings and navigation.
- Organize content logically using HTML5 semantic elements.

---

## Pages Included

1. **Home** – Main landing page of StudentHub.
2. **About** – Information about StudentHub.
3. **Register** – Student registration form.
4. **Login** – Student login page.
5. **Dashboard** – Student dashboard and important information.
6. **Events** – Displays upcoming college events.
7. **Profile** – Displays student profile information.
8. **Contact** – Contact information and contact form.
9. **Admin** – Admin-related information and controls.
10. **FAQ** – Frequently asked questions.
11. **Feedback** – Student feedback form.

---

## Technologies Used

- HTML5

- JavaScript

## Semantic HTML5 Elements Used

The pages make use of semantic elements such as:

- `<header>` – Defines the header of the page.
- `<nav>` – Contains navigation links.
- `<main>` – Contains the primary content.
- `<section>` – Groups related content.
- `<article>` – Represents independent content.
- `<aside>` – Contains related or supplementary information.
- `<footer>` – Defines the footer.
- `<form>` – Used for user input and forms.
- `<label>` – Provides accessible labels for form controls.
- `<button>` – Used for user actions.

---

## Accessibility Features

The website follows basic accessibility practices:

- Proper heading hierarchy is used.
- Form fields have associated `<label>` elements.
- Navigation is placed inside the `<nav>` element.
- Meaningful text is used for links and buttons.
- Semantic HTML5 elements are used to provide a clear document structure.
- Images include appropriate `alt` text where required.
- The page structure is designed to be understandable by screen readers.
