# Practical 2: Semantic HTML5 Pages with Accessibility-Ready Structure

## Aim
To develop static HTML5 skeletons for at least 10 StudentHub pages using semantic HTML elements and accessibility-friendly structures.

## Problem Definition
Develop static HTML5 pages for the StudentHub website, including Home, About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, and Feedback. Use semantic HTML tags and accessibility-friendly structures.

## Pages to Be Developed
1. Home
2. About
3. Register
4. Login
5. Dashboard
6. Events
7. Profile
8. Contact
9. Admin
10. FAQ
11. Feedback

## Key Questions / Analysis
1. Are semantic tags such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` used properly?
2. Are form labels, headings, image alternative text, and navigation links accessible?
3. Is the page structure consistent across all pages?

- HTML5 semantic elements
- Accessibility fundamentals
- Page linking and navigation
- Navigation menu design
- Content hierarchy
- Accessible forms and images

## Applications
- Static website foundations
- Accessible user interface design
- Student portal development

## Tools and Technologies
- Visual Studio Code

## Implementation Details
- Create at least 10 static HTML pages for StudentHub.
- Use semantic HTML5 elements to structure each page.
- Maintain consistent headers, navigation menus, main content areas, and footers.
- Use appropriate heading levels (`<h1>` to `<h6>`).
- Associate form labels with their respective input fields.
- Add descriptive `alt` attributes to meaningful images.
- Use descriptive navigation link text.
- Ensure all pages are linked correctly.
- Follow basic accessibility practices.

## Learning Outcomes
After completing this practical, students will be able to:
- Create structured HTML5 pages using semantic elements.
- Build consistent navigation across multiple pages.
- Apply basic web accessibility principles.
- Design accessible forms and image content.
- Develop clean and maintainable website structures.

## Dataset / Test Data
Sample page content for a student portal, including student information, events, registration forms, login forms, FAQs, and feedback forms.
